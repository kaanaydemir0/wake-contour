# Wake Contour

Wake Contour is a Windows desktop application that plots axial velocity ratios and wake fractions on a propeller plane. It accepts CSV or TSV files and tables pasted from Excel, and exports PNG or SVG plots.

Install Python 3.10 or later with Tcl/Tk support, extract the project ZIP, and double-click `Baslat.cmd`. The first launch installs NumPy and Matplotlib. See the [English user manual](USER_MANUAL.md) for the input format and plotting steps.
